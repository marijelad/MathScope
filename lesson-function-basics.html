Function Fundamentals

Understand the idea, see why it works, follow a complete example, then test your understanding.

1. The core idea

Mathematics becomes reliable when each step follows from a property that remains true. In this lesson, the central relationship is:

f(x) = 2x - 3
Why this works

A function assigns exactly one output to each permitted input. This makes the output predictable from the input and allows the relationship to be represented by rules, tables, graphs and mappings.

2. Worked example

Follow the reasoning one step at a time. Each transformation keeps the mathematical meaning intact.

Rule
f(x)=2x-3
Choose input
x=4
Substitute
f(4)=2(4)-3
Evaluate
f(4)=5
