Resources for better mathematical thinking

Reusable habits for solving, checking, explaining and learning mathematics.

✦

Problem-solving framework

Read → represent → reason → calculate → check. Use this sequence when a question feels unfamiliar.

✦

Graph reading checklist

Identify axes, units, scale, intercepts, turning points and the meaning of slope before calculating.

✦

Proof habits

State what is known, name the property used, and make each logical implication explicit.

✦

Error analysis

When an answer is wrong, classify the error: concept, arithmetic, notation, interpretation or checking.

✦

Study spacing

Return to a topic after a delay. Retrieval is more effective than rereading the same explanation repeatedly.

✦

Explain aloud

If you can explain why a step is valid without looking at the solution, understanding is becoming durable.
