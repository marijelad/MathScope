Frequently asked questions

Technical and learning-design notes about this demonstration project.

Does MathScope require an account?

No. This demonstration saves lesson completion locally in the browser.

Does it need a server?

No. The included version is a static front-end project and works on GitHub Pages.

Are the graphs interactive?

Yes. Lesson pages use HTML Canvas and JavaScript for responsive graph rendering.

Can more lessons be added?

Yes. The structure is designed so additional lesson pages can reuse the same visual system.

Can this become a real product?

Yes. Authentication, database-backed progress, teacher dashboards, content management and payments could be added later with a backend.

Is the contact form live?

It is a local demo. A production version should connect it to a form service or backend endpoint.
